# Business Analyzer Skill

Performs comprehensive analysis of the StudEx ecosystem based on all vault data.

## Workflow

1. Read soul.md for vision alignment check
2. Read all business profiles in Notes/Businesses/
3. Aggregate all action items, decisions, and insights from vault
4. Cross-reference against stated goals
5. Generate analysis report

## Analysis Framework

### Per Business Entity
- Current state assessment (1-10 score)
- Progress vs stated objectives
- Revenue potential (ranked)
- Time-to-revenue estimate
- Critical blockers
- Information gaps

### Overall Portfolio
- Which business to prioritize NOW for maximum ROI
- Resource allocation recommendation
- Synergies between entities
- Risk matrix

### Market Intelligence
- Compile all market data from processed chats
- Identify trends relevant to StudEx
- Flag opportunities and threats

## Output
Save analysis to Notes/Businesses/StudEx-Group/Business Analysis YYYY-MM-DD.md
