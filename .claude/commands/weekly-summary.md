Generate a weekly summary of all vault activity and business progress.

## Steps

1. Read the last 7 daily logs from Daily/
2. Scan git log for all changes this week
3. Review all notes modified this week
4. Check [[Chat Processing Log]] for chats processed this week
5. Review action items completed and outstanding

## Output Structure

### Week in Review (YYYY-MM-DD to YYYY-MM-DD)

**Key Accomplishments:**
- What was built, decided, or progressed this week

**Business Updates:**
- [[StudEx Group]] — status
- [[StudEx Meat]] — status  
- [[StudEx Global Markets]] — status

**Knowledge Captured:**
- Number of chats processed
- Notes created
- Insights extracted

**Action Items:**
- Completed this week
- Carried over to next week
- New items added

**Next Week Focus:**
- Top 3 priorities

Save the output to Daily/weekly/YYYY-WXX-summary.md
