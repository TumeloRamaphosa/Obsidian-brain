Create today's daily log entry.

## Steps

1. Check if Daily/YYYY-MM-DD.md already exists for today
2. If not, create it using the daily-log template from Templates/
3. Scan recent vault changes (git log) to auto-populate "What happened today"
4. Check for any pending action items across the vault tagged #action-item
5. List upcoming priorities from business notes

## Daily Log Structure
- Date and day of week
- Top priorities for today
- Notes created/modified today
- Action items due
- Insights captured
- Links to active business workstreams
