# Organization Rules

## The StudEx Business Hierarchy

```
soul.md (root identity)
├── [[StudEx Group]] (holding company)
│   ├── [[StudEx Meat]] (agriculture, genetics, meat)
│   ├── [[StudEx Global Markets]] (trade, export, commodities)
│   └── [[StudEx DevOps]] (technology, development, AI)
```

Every business-related note MUST connect back to one of these entities.

## Inbox Processing Flow

```
New content → Inbox/ → Process → Classify → Create Note → Link → Log
```

- NEVER leave processed content only in Inbox/ — always create a proper note
- NEVER delete Inbox files — they are the source of truth
- ALWAYS update [[Chat Processing Log]] after processing

## When to Create a New Note vs Update Existing
- **New note** — Distinct topic, new project, new person, new idea
- **Update existing** — Additional info on existing topic, follow-up on previous conversation
- **When in doubt** — Create new note and link to existing ones

## Cross-Referencing
When a topic spans multiple businesses:
1. Create the note in the most relevant business folder
2. Add [[wikilinks]] to all related business entities
3. Tag with all relevant business tags

## Archiving
- Notes are never deleted, only archived
- To archive: add `status: archived` to frontmatter
- Archived notes keep all their links intact
