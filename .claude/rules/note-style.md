# Note Writing Style

## Tone
- Direct and actionable — no fluff
- Business-focused — every note should serve a purpose
- Clear headers — scannable structure
- Bullet points over paragraphs where possible

## Structure
1. **Title** as H1 (matches frontmatter title)
2. **Overview/Summary** — 1-3 sentences, what this note is about
3. **Body** — Organized with H2/H3 headers
4. **Action Items** — If applicable, as task lists with #action-item tags
5. **Related Notes** — Footer section with [[wikilinks]] to connected notes

## Formatting
- Use tables for comparisons and structured data
- Use code blocks for diagrams (ASCII art), commands, or technical content
- Use callouts for important warnings or tips:
  - `> [!tip]` for recommendations
  - `> [!warning]` for risks
  - `> [!note]` for context
- Use `- [ ]` task syntax for action items
- Bold key terms on first use

## What NOT to Do
- Don't create notes with no links (orphans)
- Don't duplicate content that exists in another note — link to it instead
- Don't use generic titles like "Notes" or "Misc"
- Don't leave frontmatter incomplete
